ASIL-D Test Orchestrator v3.0.0

ISO 26262 ASIL-D compliant test generation and evidence pipeline for Java projects. This visual guide walks through the entire workflow from CLI invocation to evidence package generation.

1. CLI Usage Entry Point

python3 orchestrator.py run [project_dir] --workspace [dir] --token-budget [n]

Run the full pipeline (default subcommand)

python3 orchestrator.py init [project_dir]

Force re-bootstrap (clears graph store, cache, memory)

ArgumentDefaultDescription
project_dirasil-d-orchestrator/tests Path to the Java project to analyze
--workspaceasil-d-orchestrator Directory for .graph/ store and evidence/ output
--forcefalse Clear all state and re-bootstrap from scratch
--token-budget50000 Max LLM tokens per run; tasks exceeding budget are deferred

Each run follows a 10-phase pipeline. The diagram below shows the sequential flow.

4. Agent System 5 Agents × 3 Batches

All agents extend BaseAgent and use PromptBuilder to construct LLM prompts. Outputs are scored by TestQualityScorer and retried if < 70.

A Safety + Unit Tests

SafetyAgent
ISO 26262 checklist review (14 items S-01 to S-14). Checks null safety, overflow, exception handling, thread safety, resource leaks, etc.
Task: SAFETY_FAIL 1250 tokens
UnitTestAgent
Generate unit tests for uncovered methods: happy path, exception per throwsType, boundary per numeric param, branch per decision.
Task: UNIT_MISSING 1200 tokens

B MC/DC + Coverage

MCDCAgent
Analyze MC/DC gaps. Build 2^N truth tables, identify independent condition pairs, generate covering tests.
Task: MCDC_GAP 1200 tokens
CoverageAgent
Generate tests for uncovered branches. Reads mcdcCoverage and confirmedUnreachableBranches from memory.
Tasks: BRANCH_GAP */**/*** 950 tokens

C Mutation

MutationAgent
Generate kill tests for surviving mutants. Skips mutants with equivalent probability >= 0.7. Uses dataFlowNote for targeted test generation.
Tasks: MUTATION */**/*** 950 tokens

Test Quality Scorer

7 weighted dimensions — deterministic rule engine (no LLM). Score = sum of passed dimension weights + bonuses. Retry loop if score < 70.

DimensionWeightCheck
branch_assertion25Test has at least one assert statement
assertion_specificity20Asserts check concrete values (assertEquals, assertTrue, etc.)
exception_assertion15assertThrows with both type + message
mock_verification10Mockito verify() called for each stub
naming_convention10test_{method}_{scenario}_{expected} pattern
boundary_coverage10Uses min/max/zero/negative inputs
no_duplicate_logic10Body not identical to existing tests

+10 bonus if observationPoint appears in code. -10 penalty if coveredBranches already in code. Score clamped to [0, 100].
